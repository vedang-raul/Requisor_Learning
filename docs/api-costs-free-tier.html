Executive Summary

This document details the third-party API costs for a Free-tier user on Requisor Learning. Free-tier users are unaffiliated students (signed up without a university — university_id IS NULL AND university_status IS NULL). They can use core AI chat and voice (ElevenLabs TTS) up to defined caps, but all tutor AI-creation tools, voice input (STT), and AI video rendering (HeyGen) are hard-gated by role and superAdmin checks.

The caps below are from the Free Tier Plan (plans/we-have-to-build-iterative-riddle.md) and are now enforced in src/lib/ai/free-tier-limits.ts via checkFreeTierCap(), wired into the chat, TTS, and quiz routes.

⚠  Activity Assumptions — Free Tier

  • Learner: 2 sessions/week, avg 7–8 messages/session → ~60 messages/month. Chat capped at 10 messages/day. TTS capped at 3,000 chars/day and 15,000 chars lifetime.
  • TTS usage: Free user exhausts lifetime TTS cap (15,000 chars) over their account lifetime — this is a one-time cost, not recurring monthly. Daily cap (3,000 chars) means it takes at least 5 active days to reach lifetime cap.
  • STT (voice input): Not available — plan restricts STT to affiliated users only. Users must type messages.
  • Tutor AI tools: Not available — tutors require a paid seat or institutional licence.
  • Admin AI tools: Not available on free tier.
  • Token estimates: grok-3-mini averages ~1,400 input + ~400 output per turn.
  • Rate cards: grok-3-mini $0.30/M input, $0.50/M output  ·  ElevenLabs Flash v2.5 $0.30/1k chars.
  • Implementation: Cap enforcement is live in src/lib/ai/free-tier-limits.ts (checkFreeTierCap()), wired into /api/chat, /api/tts, and /api/quiz. Returns HTTP 402 with { error: "free_tier_limit", feature, resetAt } when exceeded.

🚫  Features Restricted on Free Tier — Code Gate Reference

  • ElevenLabs TTS (/api/tts) — Available but capped: 3,000 chars/day and 15,000 chars lifetime. Cap enforced via checkFreeTierCap() in src/lib/ai/free-tier-limits.ts (planned). Returns HTTP 402 { error: "free_tier_limit" } when cap hit. Only applies to users with university_id IS NULL.
  • ElevenLabs STT (/api/stt) — Not available. Plan restricts voice input to affiliated users. Returns HTTP 503. Users must type their messages.
  • HeyGen AI Video (/api/tutor/ai-video) — session.user.superAdmin === true hard check in route. All non-super-admin requests receive HTTP 403 "AI video is coming soon."
  • Lesson AI writer (/api/tutor/lesson-ai) — requires role === "tutor" || role === "admin". Returns HTTP 403 for learner role.
  • Course draft (/api/tutor/course-draft) — same role gate as above.
  • Program builder (/api/tutor/program-builder) — same role gate as above.
  • Teleprompter script (/api/tutor/teleprompter-script) — canManage() check: role === "admin" || role === "tutor". Returns HTTP 403.
  • Admin theme suggestions (/api/admin/universities/theme/suggest) — requireAccess admin gate from src/lib/server/access.ts.

2 · ElevenLabs — Voice (TTS & STT)

TTS is available to free-tier users but subject to hard caps: 3,000 characters/day and 15,000 characters lifetime (plan: plans/we-have-to-build-iterative-riddle.md, §2). ℹ  Notes, Scaling & Upgrade Path

  • TTS cap is live: src/lib/ai/free-tier-limits.ts implements checkFreeTierCap(), wired into /api/tts, /api/chat, and /api/quiz. Free users hitting the cap receive HTTP 402 { error: "free_tier_limit" }.
  • Free user definition: university_id IS NULL AND university_status IS NULL. Pending students (university_id set, university_status = 'pending') should also be treated as free-tier — a bug fix in seeReach() is part of the same plan (§1).
  • Chat cap (10 msgs/day): Also from the plan — not yet enforced. Would be added to /api/chat/route.ts alongside TTS cap.
  • To upgrade to full access: User affiliates with a university (status becomes 'active') → all caps lifted automatically. No role or key change needed for voice.
  • To enable tutor AI tools: Set user role to "tutor" or "admin" — server-side role check, no frontend change.
  • Free-tier cost at scale: 1,000 free users × $0.04/mo chat = $40/mo xAI. TTS lifetime cost is $0.45 × new users per month (one-time, not recurring). At 500 new free signups/month: +$225/mo TTS until they hit their cap or affiliate.
  • Quiz grading and accessibility: Zero marginal AI cost on free or paid tier — pure database reads.
