⚠  Activity Assumptions — Normal Tier

  • Learner: 8 sessions/week, ~7.5 messages/session → 240 messages/month. TTS on 50% of replies (avg 300 chars). Voice input: 20 recordings/month at 15 sec each.
  • Tutor (all AI tools): 2 lessons written with AI/month; 1 course draft; 2 teleprompter scripts; 1 AI video (5 min); Program Builder once per new cohort.
  • Admin: 2 theme suggestions/month; 1 video safety check.
  • Token estimates: grok-3-mini averages ~1,800 input + ~600 output tokens per chat turn.
  • Rate cards (Nov 2026): grok-3-mini $0.30/M input, $0.50/M output  ·  ElevenLabs Flash v2.5 $0.30/1k chars, v3 $0.60/1k chars, Scribe v2 $0.40/hr  ·  HeyGen Creator ~$0.15/rendered minute.

3 · HeyGen — AI Video Rendering

HeyGen is used exclusively by super-admins (checked via session.user.superAdmin === true). YouTube posting is an optional follow-on that uses YouTube's own OAuth — no additional HeyGen cost.

ℹ  Scaling & Optimisation Notes

  • HeyGen dominates for accounts producing AI videos. Learner-only accounts (no tutor AI tools, no video) cost ≈ $0.30/month.
  • Chat volume is the biggest lever. Power users (40+ msgs/day) can reach $2–4/month on xAI alone. The 20-msg/min rate limiter guards against runaway costs.
  • Context caps reduce costs: MAX_HISTORY=20 turns, MAX_STUDENT_CATALOG_LENGTH=7,000 chars, MAX_CONVERSATION_CONTEXT_LENGTH=8,000 chars — all limit per-turn input token counts.
  • Model override: Setting XAI_MODEL=grok-3 (the full model, not mini) would multiply xAI costs by approximately 5–10×.
  • Rate limiters in code (all process-local): chat 20/min · TTS 60/min · STT 20/min · lesson AI 15/min · course draft 5/min · program builder guarded by concurrency semaphore · video script 10/min · video render 6/hr.
  • Quiz grading (/api/quiz/grade) is a pure database lookup — zero AI API cost per quiz attempt.
  • YouTube posting (action: youtube) uses the tutor's own OAuth token — no HeyGen cost, no platform API cost.
