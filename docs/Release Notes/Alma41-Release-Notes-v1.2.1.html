Alma 41 — version 1.2.1

What's new since the version live on learning.requisor.io (1.2.0).

Version Replaces Release Commit Database Changes
1.2.1 1.2.0 · 1caa14e 3bd49c6 None
In short: AI-powered source citations and web search grounding are the headline additions. Learners now see citations linking to the course content behind AI responses. Tutors gain web-search-grounded research via the assistant. Free-tier usage limits are now consistently enforced across AI features.

New for learners

AI source citations Learners
  • AI responses now cite the course content they draw on — lessons, transcripts and written materials within the platform.
  • Each citation displays as a card showing the course and lesson title. Tap to expand the full list.
  • Citations are parsed from the model's response and normalised into a standard format before display.
  • Sources panel is collapsed by default; one click expands it without leaving the page.
  • The assistant only answers from content the learner can see — no external web sources.

New for tutors

Web-grounded AI research Tutors
  • Tutors can ask the assistant to research a topic — pedagogy, subject matter, industry trends, statistics — using live web search.
  • AI calls that benefit from current information use the responses API wrapper with live web search enabled.
  • Non-streaming responses are returned in a single payload, keeping the UI simpler for question-answer flows.
  • Search is scoped automatically — the model decides when to query the web and which results to cite.
  • Cited web sources appear in the same Sources panel below the assistant reply.

New for everyone

Free-tier AI usage limits Everyone
  • A new utility layer tracks and enforces the number of AI requests available on the free tier.
  • Users who reach their limit see a clear message rather than a silent failure or an unexpected charge.
  • Limits are checked before the request is sent, avoiding wasted API calls.

Improvements for everyone

Consistent citation format Everyone
  • Shared parsing utilities normalise citations from different model outputs into one internal type.
  • Components that display sources now all use the same converter, so the UI is consistent regardless of which AI call produced the answer.
